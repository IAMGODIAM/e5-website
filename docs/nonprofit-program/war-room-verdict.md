# Program name — mini war-room verdict (2026-09-20)

**Question:** name for the E5 nonprofit technology program (standalone page, `/nonprofits/`).
**Rule:** war-room consensus; never the Chairman. Recorded on branch `draft/nonprofit-program-page`.

## Options
- **A.** Assist A Boss Community Program
- **B.** The Enclave Tech Commons
- **C.** E5 Community Technology Program

## Deliberation (five lenses)

1. **Grant / federal legibility.** A reads as a business practice on a grant attachment — program officers fund entities, not practices. B is evocative but nonstandard taxonomy. **C is plain, descriptive, grant-native.** → C wins.
2. **First-visitor clarity (Pinker).** A is ambiguous (community program *of what*?). B needs a paragraph to explain "commons." **C is instantly legible** to an executive director. → C wins.
3. **Commercial-lane separation.** The concept's core complaint: the nonprofit face wears the commercial MSP name. A keeps the commercial practice's name on the nonprofit lane — defeats the purpose. B and C separate cleanly; **C puts E5 (the charity) first.** → C wins.
4. **Unity / liking.** A carries crew warmth but commercial residue. B has the strongest tribe poetry ("the commons"). C's "community" is the audience's own word. → B edges, C close.
5. **Smuggler test.** A implies an established community arm of a commercial practice (unverifiable). B implies a shared resource pool that doesn't exist yet. **C claims only what it is: a program, for the community, about technology.** → C wins.

**Slug pairing:** C → `/nonprofits/` (distinct from existing `/programs/`, audience-obvious). B → `/tech-commons/` (stale empty scaffolding already exists there from an abandoned attempt; reviving risks confusion). A → weak slug.

## Verdict (unanimous)

**C — "E5 Community Technology Program"**, route `/nonprofits/`.
Title form: "E5 Community Technology Program — E5 Enclave".
